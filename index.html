Simple, Yet Powerful Technology Stack

The Interactive CV is built on a modern, minimal stack, prioritizing speed, interactivity, and ease of deployment.

  • ⚡ HTMX: Powering all interactive elements for a server-driven UI feel, eliminating complex JavaScript frameworks.
  • 🎨 Tailwind CSS: Rapidly styled for responsive design and visual appeal on all devices.
  • 🚀 Minimal Dependencies: No build process required, making it ideal for instant deployment (e.g., GitHub Pages).
