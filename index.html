Key Features of the Interactive CV

Interactive Sections

Engage instantly with collapsible Experience, Projects, and Skills sections. Click to reveal detail using light-weight HTMX.

🌐

Multi-Language Support

Seamlessly switch between languages of choice with a clean toggle button.

📄

Print-Optimized

Looks great online, and automatically adjusts layout for a professional, clean hard copy.

🔗

Instant Copy Function

Allows visitors to instantly copy contact information (email or phone) to their clipboard with one click.

Simple, Yet Powerful Technology Stack

The Interactive CV is built on a modern, minimal stack, prioritizing speed, interactivity, and ease of deployment.

  • ⚡

    HTMX:

    Powering all interactive elements for a server-driven UI feel, eliminating complex JavaScript frameworks.

  • 🎨

    Tailwind CSS:

    Rapidly styled for responsive design and visual appeal on all devices.

  • 🚀

    Minimal Dependencies:

    No build process required, making it ideal for instant deployment (e.g., GitHub Pages).
